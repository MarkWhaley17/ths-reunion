# THS Class of 2001 Reunion

Planning hub for the Towson High School Class of 2001 reunion, happening October 9-12, 2026 in Towson, MD.

## What this project covers

- **Website:** A simple public-facing site with event details, schedule, and registration via Google Forms
- **Contacts:** Managing the class contact list and outreach
- **Announcements:** Tracking communications sent to classmates
- **Event decisions:** Logging venue choices, activity plans, and other organizing decisions

## Reunion details

- **Who:** Towson High School Class of 2001
- **When:** October 9-12, 2026
- **Where:** Towson, MD

## Project structure

```
/website      Static site files
/contacts     Contact list and outreach tracking
/docs         Event decisions, announcements, and planning notes
```
